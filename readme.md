## 🚀 About FewMath

**FewMath** is an open-source, cross-language **Mathematical Computing Library** focused on providing pre-built, efficient, and accurate solutions to complex mathematical problems in **C++, Java, Python, and JavaScript**.

No need to write lengthy math functions from scratch — just input the values and get instant results with best-in-class performance! 💪

## 🛠️ Installation

### 🔸 Python
```
#include "fewmath.h"

int main() {
    int result = FewMath::Algebra::gcd(36, 60);
    std::cout << result << std::endl; // Output: 12
}
```
