FewMath - Universal Math Library

A cross-language mathematical library for complex calculations

📌 Introduction

FewMath is an open-source mathematical library designed to simplify complex calculations across multiple programming languages. It supports C++, Java, Python, and JavaScript.

⚡ Installation

Python:

pip install fewmath

JavaScript (Node.js):

npm install fewmath

C++:

# Include fewmath.h and link the shared library

🚀 Quick Start

Here’s how you can use FewMath for basic algebra operations:


# Python Example
target = fewmath.algebra.gcd(36, 60)
print(target)  # Output: 12
                

// JavaScript Example
const fewmath = require('fewmath');
console.log(fewmath.algebra.gcd(36, 60)); // Output: 12

🛠 Supported Languages

  • C++
  • Java
  • Python
  • JavaScript
