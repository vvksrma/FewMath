FewMath - High-Performance Math Library

A cross-language mathematical library for efficient and accurate calculations

📌 Introduction

FewMath is an open-source mathematical library optimized for high-speed numerical computations. It supports C++, Java, Python, and JavaScript, making it a versatile choice for developers.

⚡ Installation

Python:

pip install fewmath

JavaScript (Node.js):

npm install fewmath

C++:

# Include "fewmath.h" and link the shared library

🚀 Quick Start

Here’s how you can use FewMath for computing GCD:


# Python Example
import fewmath
result = fewmath.algebra.gcd(36, 60)
print(result)  # Output: 12
                

// JavaScript Example
const fewmath = require('fewmath');
console.log(fewmath.algebra.gcd(36, 60)); // Output: 12
                

// C++ Example
#include "fewmath.h"
#include 
int main() {
    std::cout << algebra::gcd(36, 60) << std::endl; // Output: 12
    return 0;
}
