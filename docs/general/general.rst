FewMath - Universal Math Library
================================

FewMath is a high-performance, cross-language mathematical library designed to simplify complex calculations across multiple programming languages.

.. contents:: Table of Contents
   :local:

📌 Introduction
---------------
FewMath provides efficient mathematical operations in C++, Java, Python, and JavaScript. It is designed for ease of use, speed, and accuracy.

⚡ Installation
---------------
Install FewMath in your preferred language:

**Python**
.. code-block:: bash

    pip install fewmath

**JavaScript (Node.js)**
.. code-block:: bash

    npm install fewmath

**C++**
Include `fewmath.h` and link the shared library.

🚀 Quick Start
--------------
Using FewMath for basic algebra operations:

**Python**
.. code-block:: python

    import fewmath
    result = fewmath.algebra.gcd(36, 60)
    print(result)  # Output: 12

**JavaScript**
.. code-block:: javascript

    const fewmath = require('fewmath');
    console.log(fewmath.algebra.gcd(36, 60)); // Output: 12

🛠 Supported Languages

- C++
- Java
- Python
- JavaScript
